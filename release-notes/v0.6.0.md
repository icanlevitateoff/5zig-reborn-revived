## Changes
- **Menus and messages now say "5Zig Reborn Revived"** instead of "The 5zig Mod": menu titles such as "5Zig Reborn Revived - Accounts", the "5Zig Reborn Revived..." button in Options, the keybind category in Controls, chat prefixes and desktop notifications.
- **Mod Menu support:** the config button opens 5zig's settings, and the mod's page now links to CurseForge, the GitHub issue tracker and the source code.
- **Cloth Config support:** with Cloth Config installed, the config button opens 5zig's settings as a Cloth Config screen, with one tab per section. Modules, the HUD layout editor, accounts and the other screens are a click away in the full 5zig menu. Without Cloth Config, 5zig's own menu opens instead.
- Closing 5zig's settings now returns to the screen you opened them from (Options or Mod Menu) instead of going back to the game.

## Fixes
- **Notifications no longer show up twice after switching accounts** (for example "You are no longer AFK!"). Switching accounts left the old account's helpers running alongside the new ones, so AFK, timers, search and server stats were all handled twice.
- **The game closes cleanly again.** The background thread that retries the 5zig network connection could keep Minecraft from exiting, ending in a "Client shutdown" crash report. That connection now also uses a single thread instead of up to two per CPU core.
- **Joining a server no longer fails now and then with a Mojang 429 error**, mostly right after launch or when using the last-server button. 5zig's own network logs in through the same Mojang service the game uses to join servers, and when both happened at once Mojang refused one of them. The 5zig network now waits until 20 seconds after launch, and 20 seconds after you start joining a server, before it logs in.
- **Keyboard shortcuts in 5zig's menus work again.** Since the move to Fabric, several screens never saw the keys they listen for: Space, Delete and Ctrl+D in the coordinates clipboard, Ctrl+F to search the settings, F5 to refresh server lists and Up/Down for sent-message history in 5zig chats. Search boxes now also update when you press Backspace.
